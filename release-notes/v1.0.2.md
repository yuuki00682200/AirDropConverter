AirDropで受信したHEIC/HEIF画像をPNG・JPEGへ変換するmacOSメニューバーアプリです。

## 更新内容

- 受信途中の画像や、変換中に届いた画像の検出漏れを修正。
- バックグラウンド変換と手動ファイル選択を追加。
- 画像の向きを正しく反映し、同名の出力ファイルを上書きしないよう修正。
- 「変換後にHEICを削除」をオンにすると、変換成功後に元画像をゴミ箱へ移動。失敗時や変換中に元画像が変更された場合は保持。
- アクセス権・変換・ログイン時起動設定のエラーを表示。
- 設定の保存、日本語表示、Applicationsへのコピー処理を改善。

## ダウンロードと起動

1. 下の **AirDropConverter-v1.0.2.zip** をダウンロードして解凍。
2. AirDropConverter.appをApplicationsフォルダへコピーして起動。
3. Downloadsへのアクセスを許可。通知は任意。
4. メニューバーから出力形式や「変換後にHEICを削除」を設定。

macOS 14.0以降、Apple Silicon・Intel両対応（Universal）。

Developer ID Application（MEMEMAKER, K.K.）で署名し、Appleの公証を取得済みです。公証チケットを添付し、Gatekeeperの検証も成功しています。

## 対応範囲と検証

PNG/JPEGに対応。WebPはmacOSのImageIOが書き出しに対応している環境のみ表示されます。WebPエンコーダーは同梱していません。HEIFの主画像を変換し、Live Photoの動画や深度情報は出力しません。

実HEIC画像による形式・向き・同名ファイル保護・破損入力・一時ファイル清掃の回帰テスト、AirDrop属性判定、受信安定待ち・処理中の受信保持・同名再受信のテストが成功。Debug/Releaseビルドとローカル起動を確認しました。

iPhoneからの実際のAirDrop、再ログイン後の自動起動、Intel実機での起動は未検証です。

SHA256SUMS.txtでZIPのチェックサムを確認できます。
