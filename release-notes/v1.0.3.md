## 新しいロゴとメニューバーSymbol

- アプリアイコンを、新しいAirDropConverterロゴに変更しました。
- メニューバーのアイコンを、写真と下向き矢印の専用Symbolに変更しました。
- macOSのテンプレート表示で背景に合わせた色を使用し、監視停止時は薄く表示します。
- 同じリポジトリに、日本語・英語対応のサービスLPを追加しました。

### インストール

AirDropConverter-v1.0.3.zipを解凍し、AirDropConverter.appをApplicationsへコピーしてください。更新時は旧アプリを終了して置き換えてください。

macOS 14.0以降、Apple Silicon・Intel対応（Universal）。
Developer ID Applicationで署名し、Appleの公証とGatekeeperの検証が成功しています。

PNG/JPEGに対応。WebPはmacOSの書き出し対応環境のみ表示されます。画像変換はローカルで行い、変換成功後に元画像をゴミ箱へ移動する設定を利用できます。

Universal Releaseビルド、署名、公証チケット添付・検証を確認済みです。iPhoneからの実際のAirDrop、再ログイン時の起動、Intel実機での起動は未検証です。

SHA256SUMS.txtでZIPのチェックサムを確認できます。
